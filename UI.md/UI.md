# NoAITell UI 设计说明（定稿，2026-11-01）

来源：ChatGPT 第二轮半 + GLM（ZCode）第二轮合并，Andi 裁决。SPEC.md 为准，本文件只细化 UI。

## 裁决记录
- 常驻布局采用双栏工作台（原文·检测 | 结果·Diff，约 55:45）＋可折叠检测侧栏——SPEC 修订补充一已定，不采用 GLM 的常驻单画布方案；采纳 GLM「diff 按需承接对照」的思想：结果栏内以 结果/Diff 两个 tab 切换。
- 其余 GLM 细化（密度 before→after、0 命中分类置灰保留、低置信不上画布、失效态灰色虚线、导出随输出模式联动）全部采纳。

## 布局与层级
- Header：Logo + 英文副标题 "Spot AI writing patterns. Keep your meaning." + 中文副标题「检查并清理 AI 文本中的格式残留与模板化表达」+ LocalBadge（盾形图标 +「本地运行 · 不上传」，hover 弹层「文本不出本机」，常驻顶栏）。首屏不设大 Hero，工具即首屏。
- SummaryBar（摘要条）：句式命中密度（处/千可见字符）、格式命中数、待复核数三者分开呈现，永不合成单一「AI 分」；清理后密度显示 before→after。附口径小字：数值不代表 AI 生成概率。
- 主区双栏：左 SourceEditor（原文·检测），右 ResultPanel（结果·改动对照），结果面板高度至少 480px。
- 检测详情（FindingsList / HitCard）位于右栏抽屉或主区下方，避免常驻第三个狭窄文本栏。

## 组件清单
- CategoryChips：四大类（复制与格式残留 / 排版与字符 / 模板化表达 / 链接隐私）色点+名称+计数；点击筛选画布与详情列表，再点取消，可多选；筛选不改变清理开关；0 命中分类置灰保留（传达「查过了」）。
- SourceEditor：原生可编辑区（粘贴/编辑/加载示例）；检测高亮走独立预览层，不污染编辑；高亮=分类色底（alpha 8–15%）+ 下划线（线型表置信：实线=可清理、虚线/点线=需复核）；低置信命中默认不在正文着色、仅计入侧栏；提供「隐藏高亮」纯阅读开关；点击命中定位详情卡。
- FindingsList / HitCard：字段=规则名 / 命中原文 / 置信标签（可清理 / 需复核）/ 命中解释（位置→句式→为什么值得复核）/ 操作【忽略此项｜下一处】。句式类只提示，无删除开关。
- CleanupOptions：只列可清理类别的开关 + 两个动作：「清理所选项」「仅清理高置信项」；输出模式分段控件：纯文本发布 / 保留 Markdown（影响导出 .txt/.md 与 diff 呈现）。
- ResultPanel：清理后文本 + Diff 视图（逐处改动可独立接受/拒绝）；原文永不被覆盖；清理一律从「原始快照 + 当前选项」重新计算，禁止在上次结果上累积应用。
- ActionBar：清理、复制结果、撤销、恢复原文；按钮按状态禁用，不执行空操作。
- HistoryStack：记录每次清理/忽略，支持单步撤销与回滚到原文；忽略状态与清理开关分开管理。
- Footer：FAQ、方法说明、隐私声明，不影响工具首屏可见性。

## 关键状态
- 空状态：画布中置引导（一句话 +「试个示例」按钮）；摘要显示「—」；无文本时扫描禁用；LocalBadge 在空状态放大展示一次建立信任。
- 扫描中：本地即时计算；<300ms 不显示进度（防闪烁）；画布只读、高亮逐批浮现。
- 有命中：摘要、分类计数、可定位高亮齐备；中低置信必须逐项确认，高置信可批量清理。
- 无命中：显示「未发现当前规则覆盖的问题」+ 边界声明（基于当前规则与统计特征，不构成「真人证明」）；仍可复制原文。红线：禁止任何「100% 真人」类表述。
- 清理预览：Diff 先行，确认后才应用。
- 已清理：显示已处理数 + 剩余待复核数；画布可切「原文/清理稿」；复制/撤销/恢复可用。
- 失效态（文本已修改）：用户编辑输入后，旧高亮退化为灰色虚线，顶部提示「文本已修改，结果可能过期【重新体检】」；旧命中定位必须重算。

## 色板原则
- 分类色：蓝=模板化表达（句式）、琥珀=排版与字符、绿=复制与格式残留、紫=链接与引用。四色在 chips、高亮、详情三处同色；颜色只表类别，永不表置信度；不用警报红。
- 双通道编码：色相=分类，下划线线型=置信档；颜色永不承载唯一信息（配图例、文字标签、键盘焦点样式）。
- 正文对比度 ≥4.5:1（WCAG AA）；选中命中底色加深至约 25% 并加外框；diff 增删不用红绿单编码（叠加删除线/加粗）；暗色模式单独调色重测，不做简单反转。

## 移动端（<768px）
- 单列：原文 / 结果 / Diff 三 tab 切换并保留各自滚动位置；摘要压缩两行；chips 横向滚动；详情用底部抽屉（半屏高、上滑展开），不遮挡当前命中上下文；底部固定操作栏最多两个主操作，其余进溢出菜单；触控目标 ≥44px；编辑时不弹抽屉；定位为「可查看、可轻清理」，重度清理引导回桌面。

## 工程约束
- 引擎流水线：分段 → 语种识别 → 分句 → 局部匹配器（禁止单条全局正则跑全场）；代码块、引用块、链接内、被忽略片段不匹配。
- 结构匹配与风格判断分离：命中是结构事实，风格提示只给低–中置信；密度与重复比孤立命中权重更高。

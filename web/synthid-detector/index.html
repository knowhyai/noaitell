SynthID Detector: Why Public Detection Does Not Cover Text

Learn the difference between public SynthID Detector media support and SynthID Text developer detection.

SynthID Detector and SynthID Text are related names with different practical access paths. Gemini has used SynthID Text since 2024, but the public SynthID Detector does not cover text. A public detector for supported visual or audio media should not be presented as a service that authenticates a pasted paragraph.

Google’s SynthID Text developer documentation describes a statistical generation method and probabilistic detection. The open implementation allows developers to build watermarking into their own model pipeline. Running a reference detector requires appropriate configuration and calibration; it does not automatically grant access to the watermark secrets used by a production Gemini service.

This distinction matters because a detector result applies to a specific scheme, not to all AI text. Different tokenizers, keys, generation settings, passage lengths and editing histories can affect what a detector can evaluate. An interface that accepts text is not by itself evidence that it can verify Google’s deployed provenance signal.

NoAITell is a local text cleanup tool, not a SynthID verification endpoint. Use the embedded cleaner to inspect formatting residue, invisible artifacts and writing patterns. Review the findings before applying selected changes, and choose whether to keep Markdown based on where you plan to publish. The tool does not send your paragraph to Google.

Character cleaning cannot remove SynthID Text because the signal is carried through words. Heavy rewriting can disturb a statistical pattern, but the cleaner does not perform that operation or certify its outcome. A zero-match character scan is compatible with watermarked prose, just as unusual characters can occur in human-authored documents.

If your task requires provenance evidence, preserve the original and establish which authorized detector can answer the question. Document the limits of any result rather than treating it as a universal verdict. If your task is editing, evaluate clarity and factual accuracy directly. Those goals are useful regardless of whether a particular model’s statistical watermark can be checked by the tools available to you.
